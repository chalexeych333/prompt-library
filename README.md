# Prompt Library

Моя личная библиотека переиспользуемых промптов для работы с ИИ.

Библиотека предназначена для хранения, тестирования и версионирования промптов, которые можно повторно использовать в различных проектах.

## Структура библиотеки

Промпты хранятся в папке `prompts`.

Каждый промпт содержит:

* название;
* версию;
* владельца;
* теги;
* цель;
* шаблон промпта;
* переменные;
* пример входных данных;
* пример результата;
* тест-кейсы;
* историю версий.

## Версионирование

Для промптов используется следующая схема:

* `v1.0` — первая рабочая версия;
* `v1.1` — небольшие улучшения;
* `v2.0` — существенное изменение структуры или логики промпта.
